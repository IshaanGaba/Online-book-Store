# Online-book-Store

## 📖 Overview
The **Online Book Store Web App** is a fully functional web application that allows users to browse, search, and purchase books online. The platform provides an intuitive user interface for book lovers to explore various categories, add books to their cart, and complete purchases.

## 🚀 Features
- **User Authentication**: Secure login and signup functionality.
- **Book Catalog**: Browse books with details like title, author, price, and genre.
- **Search & Filter**: Search books by title, author, or category.
- **Shopping Cart**: Add books to cart and proceed to checkout.
- **Order Management**: Track and view past orders.
- **Admin Dashboard**: Manage books, users, and orders.
- **Responsive Design**: Works on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT (JSON Web Tokens)
- **Payment Gateway**: (If implemented) Stripe or PayPal API
- **Storage**: Cloudinary for book cover images (Optional)

## 🏗️ Installation & Setup
### Prerequisites
Ensure you have the following installed:
- Node.js
- MongoDB (Local or Cloud-based like MongoDB Atlas)

### Steps to Run Locally
```sh
# Clone the repository
git clone https://github.com/your-username/online-book-store.git
cd online-book-store

# Install dependencies
npm install
```
